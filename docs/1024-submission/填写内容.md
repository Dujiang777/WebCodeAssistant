```
《我把一个 AI 编程工作台养成了暗房》

起点是一个很具体的需求：想要一个打开网页就能用、AI 能改代码但「人不拍板不落盘」的编程助手。它现在叫 Web Code Assistant，线上跑了三个月，接了真实的 DeepSeek 模型。

技术栈：Spring Boot 3.5 + Java 21 虚拟线程 + LangChain4j；前端 React 18 + Vite + Monaco 编辑器；MySQL 8 + Redis 7（可降级）。

和 WorkBuddy 的协作方式：35 个以上批次迭代，每批都配浏览器自检剧本 + 4 条接口基线（83/65/114/15 零失败）+ 3 套设计契约剧本，全绿才提交上线。UI 走「暗房黄铜」主题：胶片帧号文件树、计划卡显影进度条、补丁卡「已冲印」印章。

安全是结构不是提示词：模型只有 list_dir / read_file / grep / propose_patch 四个工具，写盘入口只有用户点的「应用」；补丁生成时就干跑算影响面，磁盘变了会标「底片已变」并禁用应用。

也踩过真 bug：切走会话再回来，进行中的任务进度会丢——根因是切换时无条件清空了内存态，而 SSE 续流只回放断连后的事件。改成按会话存快照后修复，回归剧本坐实。
```
