# 项目编码规则（会自动注入 AI system prompt）

> 放在工作区根目录、名字为 `.coding-rules.md` 的文件会被 Web Code Assistant 读取并注入到
> system prompt 里。用它把团队约定固化下来，避免每次对话都要重复交代。

## 通用

- 所有 public 方法必须有中文 Javadoc，说明「做什么」与「为什么不这么做」。
- 不使用 `System.out.println`，统一用 SLF4J。
- 不做没有必要的抽象：只有在出现第二处调用时才提取接口。

## 依赖注入

- 一律使用**构造器注入**，字段声明为 `private final`。
- 禁止 `@Autowired` 字段注入，禁止 `@Autowired` setter 注入。
- 只有一个构造器时不加 `@Autowired` 注解。

## 异常

- 业务异常继承 `RuntimeException`，类名以 `Exception` 结尾。
- 不吞异常：`catch` 块要么处理，要么包装后抛出，不允许空 `catch`。

## 重命名文件 / 大范围改动

- 一次补丁只改一个文件。
- 移动或重命名类时，先确认所有引用点，再分多次补丁提交。
